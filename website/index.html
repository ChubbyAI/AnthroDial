Code & Release Scope

MIT-licensed evaluation code, prompts, rubrics, configuration templates, and historical summary results.

Persona cards, scenario cards, bindings, raw conversations, case-level judge explanations, training pipelines, and model weights are not included. Prepare your own inputs and model endpoints to run an evaluation.

python -m pip install -r requirements.txt
python apps/benchmark/scripts/run_benchmark.py --config configs/chatbot/qwen3.5-397b-a17b.yaml

Set OPENAI_API_KEY and JUDGE_API_KEY for your services. New runs write to runs/; published results remain in results/. Configuration templates cannot guarantee reproduction of historical API responses.
